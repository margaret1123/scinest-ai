## SciNest 是什么？

**用你自己的 AI Key，把研究材料变成可编辑的学术成果。**

SciNest 是面向学生、教师和研究人员的桌面工作台。你用自己的 API Key（支持 OpenAI、Claude、DeepSeek、Gemini、智谱、Kimi、豆包、Mistral、通义千问等 12+ 模型厂商），导入项目材料，SciNest 帮你生成：

- **论文、综述、开题报告和章节**，支持引用标注与定向修改
- **科研图与图形摘要**，支持可编辑图层、标签和箭头
- **答辩 PPT**，21 套设计模板，材料驱动大纲
- **参考文献列表**，支持文献追踪与导出

不需要写 Prompt。App 就是 Prompt。

## 核心功能

### 📝 AI 写论文
从你的研究材料生成论文草稿，支持结构化大纲、章节编辑和证据绑定。

<img src="public/scinest/writing-workspace-proof-v3.webp" alt="论文写作工作区" width="100%" />

### 🔬 科研图
AI 生成基础图像 + 可编辑矢量叠加层（标签、箭头、图注）。支持机制图、技术路线和图形摘要。

<img src="public/scinest/figures-ui-zh.webp" alt="科研图编辑器" width="100%" />

### 📊 PPT 生成
把研究材料变成结构化演示文稿。21 套设计模板，材料驱动大纲，可编辑文本，可导出 PPTX。

<img src="public/scinest/ppt-ui-zh.webp" alt="PPT 编辑器" width="100%" />

### 📚 参考文献
引用感知输出，文献追踪，参考文献库，支持标准格式导出。
